# Portfolio

My personal site, built with plain HTML, CSS and a little JavaScript. No build step.

Live at https://delusion-arch.github.io/portfolio-website/

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Structure

- `index.html`: the page
- `style.css`: styles, with light and dark themes that follow the system setting
- `script.js`: keeps the footer year current
- `assets/`: project screenshots (demo data)
